## 백로그 파일 업데이트 요청

```text
오늘 진행한 3회차 디자인 수정 결과를 `docs/design-backlog/D-001.md`에 반영해줘.

반영할 것:
- Status를 done 또는 blocked로 변경
- 실제 수정한 URL과 파일
- 검증 결과
- before/after 요약
- 다음에 고칠 후보 D-002가 있다면 `docs/design-backlog/D-002.md` 초안으로 제안

조건:
- AGENTS.md에는 완료 내역이나 백로그 본문을 적지 마.
- AGENTS.md는 규칙이 부족할 때만 짧게 보강해.
- 사실 확인된 내용만 적어.
- 아직 수정하지 말고 변경 문안만 먼저 보여줘.
```
