## 오늘의 원칙

```text
기존 2회차 레포에서 이어서 한다.
Plan mode로 먼저 계획을 받는다.
브라우저 / Browser 태그로 화면을 같이 본다.
레퍼런스는 전체 복제가 아니라 원하는 요소 하나만 가져온다.
AGENTS.md에는 반복 규칙과 백로그 위치만 남기고, 실제 백로그는 docs/design-backlog/에 작성한다.
수정 후에는 모바일과 build로 확인한다.
```
