# 01. 기존 레포와 Codex 채팅 확인

## 목표

3회차를 시작할 기준 레포와 Codex 채팅을 확인합니다.

## 확인할 것

```text
내 개인 레포 URL:
GitHub Pages URL:
로컬 프로젝트 폴더:
Codex 프로젝트에 연결된 폴더:
2회차에서 만든 페이지: /, /about, /projects, /posts
AGENTS.md 위치:
```

## Codex에게 보낼 프롬프트

```text
3회차 디자인 수정 작업을 시작하려고 해.
새 프로젝트를 만들지 말고, 현재 Codex에 열린 기존 2회차 Astro 개인 홈페이지 레포에서 이어서 진행해줘.

먼저 아래만 확인해줘.
1. 현재 작업 폴더가 맞는지
2. package.json이 있는지
3. src/pages 구조가 어떻게 되어 있는지
4. AGENTS.md가 있는지
5. /, /about, /projects, /posts 페이지가 있는지
6. git status가 깨끗한지
7. npm run dev와 npm run build를 실행할 수 있는 상태인지

중요:
- 아직 파일을 수정하지 마.
- 먼저 확인 계획을 말해줘.
- 내가 승인하면 확인 명령만 실행해줘.
```

## Ready Gate

- [ ] 기존 2회차 레포에서 시작한다.
- [ ] 새 프로젝트를 만들지 않는다.
- [ ] AGENTS.md가 있는지 확인했다.
- [ ] 로컬 URL을 열 수 있다.
