# 14. 모바일 확인

## 목표

수정 결과가 모바일에서도 깨지지 않는지 확인합니다.

## 최소 viewport

```text
390x844
768x1024
1440x900
```

시간이 부족하면 390x844만 확인합니다.

## Codex에게 보낼 프롬프트

```text
@브라우저 또는 @Browser로 수정한 페이지를 아래 viewport 기준으로 확인해줘.

- 390x844
- 768x1024
- 1440x900

확인할 것:
1. 제목 줄바꿈
2. Navigation 터치 가능성
3. 카드 padding과 gap
4. 본문 줄 길이
5. 가로 스크롤 여부

문제가 있으면 바로 수정하지 말고, 가장 작은 수정 계획만 먼저 말해줘.
```
