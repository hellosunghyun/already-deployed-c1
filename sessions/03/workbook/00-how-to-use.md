# 00. 워크북 사용법

## 오늘의 기준

3회차는 **새로 시작하지 않습니다.**

이미 2회차에서 만든 레포가 있고, Codex에 가져왔고, 가능하면 그때 쓰던 채팅에서 이어서 진행합니다.

```text
2회차 레포
→ 같은 Codex 프로젝트 / 같은 채팅
→ Plan mode로 수정 계획
→ 브라우저 주석 또는 스크린샷
→ 작은 디자인 수정
→ 모바일 / build 검증
```

## Plan mode란?

Plan mode는 Codex가 바로 코드를 고치기 전에 맥락을 읽고, 질문하고, 실행 계획을 만드는 모드입니다.

쓸 때:

```text
복잡한 디자인 수정
여러 파일이 바뀔 수 있는 작업
레퍼런스를 보고 토큰을 적용하는 작업
모바일까지 확인해야 하는 작업
```

여는 방법:

```text
/plan
```

또는 앱에서 지원하면:

```text
Shift + Tab
```

## Plan을 실행하는 기본 흐름

```text
1. /plan 으로 계획을 받는다.
2. 수정 파일, 리스크, 검증 방법을 확인한다.
3. 실행할 항목 1개만 고른다.
4. "좋아. 이 계획의 1번 항목만 실행해줘"라고 보낸다.
5. 수정 후 브라우저와 build로 검증한다.
```

바로 실행시키지 않습니다.

```text
아직 수정하지 말고 먼저 계획만 보여줘.
내가 승인하면 선택한 항목만 실행해줘.
```

## 브라우저 태그

Codex UI 언어에 따라 태그가 다를 수 있습니다.

```text
한국어 UI: @브라우저
영어 UI: @Browser
```

둘 중 자동완성되는 것을 씁니다.

```text
@브라우저 http://localhost:4321/ 을 열어줘.
```

또는

```text
@Browser http://localhost:4321/ 을 열어줘.
```

## 태그가 안 될 때

브라우저 플러그인이 꺼져 있을 수 있습니다.
아래 경로를 확인합니다.

```text
설정
→ 통합
→ 브라우저
→ 브라우저 켜기
→ 주석 스크린샷: 항상 포함
→ 승인: 항상 허용 또는 매번 확인
```

화면 예시는 [브라우저 설정 스크린샷](../assets/codex-browser-settings.png)을 참고합니다.

## 막혔을 때 기본 질문 템플릿

```text
나는 3회차 워크북의 [단계 이름] 단계에 있어.
수업 레포 링크는 https://github.com/hellosunghyun/already-deployed-c1 이야.
내 개인 레포 링크는 [여기에 입력] 이야.

기준:
- 새 프로젝트가 아니라 2회차에서 만든 기존 Astro 개인 홈페이지를 이어서 작업 중이야.
- Codex에 이미 레포를 가져왔고, 가능하면 기존 채팅에서 진행 중이야.

현재 상태:
- 열린 URL:
- 고치고 싶은 영역:
- 화면 크기:
- 문제:
- 원하는 방향:
- 방금 실행한 명령어 또는 요청:
- 나온 오류 또는 이상한 화면:

제약:
- 새 라이브러리는 추가하지 마.
- 관련 없는 파일은 수정하지 마.
- 기존 데이터 구조와 배포 설정은 유지해.
- 아직 수정하지 말고 원인 후보와 다음 한 단계만 제안해줘.
```
