# 10. 모바일 화면 확인과 반응형 수정

## 목표

3회차 디자인 수정 결과가 모바일 화면에서도 깨지지 않는지 확인합니다.

## 왜 하는가

데스크톱에서 좋아 보이는 디자인이 모바일에서 제목 줄바꿈, 가로 스크롤, 카드 밀도 문제를 만들 수 있습니다.
모바일 확인은 디자인 polish가 아니라 필수 검증입니다.

## 최소 확인 viewport

```text
390x844  모바일 기준
768x1024 태블릿 기준
1024x768 작은 노트북 기준
1440x900 데스크톱 기준
```

## 확인할 문제

```text
가로 스크롤이 생기는가
제목이 4줄 이상으로 길게 깨지는가
Navigation 링크가 너무 붙는가
카드가 너무 좁거나 빽빽한가
CTA나 자세히 보기 링크가 터치하기 쉬운가
본문 줄 길이가 너무 긴가
섹션 위아래 여백이 과하거나 부족한가
```

## Codex에게 보낼 프롬프트

```text
3회차 디자인 수정 결과를 모바일과 반응형 기준으로 검증하고 싶어.

Codex Browser에서 아래 viewport 기준으로 확인해줘.

- 390x844
- 768x1024
- 1024x768
- 1440x900

확인할 URL:
- /
- /about
- /projects
- /posts

확인할 것:
1. 가로 스크롤이 생기는지
2. Navigation이 깨지는지
3. Home 제목이 너무 많이 줄바꿈되는지
4. Projects 카드가 모바일에서 읽기 쉬운지
5. Posts 목록이 모바일에서 너무 빽빽하지 않은지
6. 링크나 버튼이 터치하기 쉬운지
7. 수정 전보다 나빠진 부분이 있는지

중요:
- 문제를 발견해도 바로 대규모 수정하지 마.
- 문제 목록을 먼저 만들고, 가장 작은 수정 계획을 제안해줘.
- 새 라이브러리 추가하지 마.
- media query, clamp, max-width, gap 조정처럼 CSS 중심으로 해결해줘.
```

## 모바일 수정 요청 예시

```text
390px 모바일에서 Home 제목이 4줄로 깨져.
데스크톱 제목 크기는 크게 유지하되, 모바일에서는 제목 font-size와 line-height를 줄이는 방향으로 수정해줘.
가능하면 clamp()나 기존 media query 안에서 최소 수정해줘.
```

```text
390px 모바일에서 Projects 카드가 너무 답답해.
카드 내부 padding을 조금 줄이고, tools 태그는 wrap되게 유지해줘.
카드 자체는 1열을 유지하고 데이터 구조는 바꾸지 마.
```

## 체크박스

- [ ] 390x844에서 Home을 확인했다.
- [ ] 390x844에서 Projects를 확인했다.
- [ ] 390x844에서 Posts를 확인했다.
- [ ] 768px 이상에서도 확인했다.
- [ ] 가로 스크롤 여부를 확인했다.
- [ ] 모바일에서 고친 문제가 desktop을 망가뜨리지 않았는지 확인했다.

## Ready Gate

다음 단계로 넘어가기 전에 아래가 되어 있어야 합니다.

- 모바일에서 심각한 깨짐이 없습니다.
- 심각한 깨짐이 있다면 문제와 다음 수정 프롬프트가 기록되어 있습니다.
- 데스크톱과 모바일 둘 다 확인했습니다.
