# 02. Plan mode로 수정 계획 받기

## 목표

Codex가 바로 CSS를 고치지 않게 하고, 먼저 디자인 수정 계획을 받습니다.

## Plan mode 시작

Codex 입력창에 아래 중 하나를 사용합니다.

```text
/plan
```

또는 지원되는 환경에서는:

```text
Shift + Tab
```

## Plan 요청 프롬프트

```text
3회차 디자인 수정 계획을 세워줘.
새 프로젝트를 만들지 말고 기존 2회차 Astro 홈페이지에서 이어서 진행해.

목표:
- Home / Navigation / Projects / Posts 중 하나의 화면 문제를 고친다.
- 레퍼런스가 있으면 전체 복제가 아니라 원하는 요소 하나만 가져온다.
- 수정 후 브라우저와 390px 모바일, npm run build로 확인한다.

계획에 포함할 것:
1. 현재 화면에서 먼저 확인할 URL
2. 후보 문제 3개
3. 각 문제의 수정 대상 파일 후보
4. 새 라이브러리 없이 고칠 수 있는 방법
5. 가장 작은 실행 단위 1개
6. 검증 방법
7. 되돌릴 때 확인할 git 상태

아직 파일을 수정하지 마.
계획만 보여줘.
```

## 좋은 Plan의 기준

```text
- 수정 대상 URL이 있다.
- Target이 하나로 좁혀져 있다.
- 바꿀 파일 후보가 있다.
- 하지 않을 일이 적혀 있다.
- 확인 방법이 있다.
```

10단계에서 **선택한 백로그 항목 1개만** 실행합니다.
