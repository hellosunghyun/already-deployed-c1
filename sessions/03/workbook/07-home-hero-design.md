# 07. Home hero 디자인 챌린지

## 목표

Home 첫 화면의 시각 위계와 다음 행동 안내를 개선합니다.

## 왜 하는가

Home은 방문자의 첫인상입니다.
방문자는 첫 화면에서 "이 사이트가 누구의 사이트인지", "무엇을 볼 수 있는지", "어디로 가면 되는지"를 빠르게 알아야 합니다.

## 고칠 수 있는 문제

- 제목이 너무 크거나 작다.
- 소개 문장이 길거나 약하다.
- About / Projects / Posts로 가는 링크가 약하다.
- 제목과 설명 사이 간격이 어색하다.
- 모바일에서 제목이 4줄 이상으로 깨진다.
- 첫 화면 여백이 과해서 콘텐츠가 너무 아래에 있다.


## 레퍼런스 요소를 쓰는 경우

Home hero에서는 레퍼런스 전체가 아니라 아래 요소 중 하나만 가져옵니다.

```text
추천 선택 요소:
- Hero title scale
- Layout rhythm
- Color role 중 muted text 역할

가져오지 않을 것:
- 레퍼런스의 로고, 이미지, 배경 전체
- 외부 폰트
- 스크롤 애니메이션
- 전체 컬러 팔레트 교체
```

## Codex에게 보낼 프롬프트

```text
Home hero 영역을 디자인 관점에서 개선하고 싶어.

현재 상태:
- Astro 개인 홈페이지다.
- Home / About / Projects / Posts 구조가 있다.
- 공통 Layout과 Navigation이 있다.
- Codex Browser에서 Home 화면을 확인할 수 있다.

대상:
- URL: /
- Viewport: desktop과 390px mobile 둘 다 확인
- Target: Home hero 영역

레퍼런스 토큰 브리프가 있다면:
[여기에 color / typography / spacing / radius / shadow / layout 요약 붙여넣기]

목표:
1. 처음 온 사람이 내가 누구인지 빠르게 알 수 있게 한다.
2. 한 줄 소개가 제목보다 약하지만 잘 읽히게 한다.
3. About / Projects / Posts로 가는 다음 행동이 보이게 한다.
4. 모바일에서 제목이 너무 많이 줄바꿈되지 않게 한다.
5. 기존 톤은 유지하고 전체 리디자인은 하지 않는다.
6. 레퍼런스 토큰이 있다면 Home hero에 필요한 typography와 spacing만 작게 반영한다.

수정 방향:
- 제목 크기는 필요하면 `clamp()` 같은 유동 크기로 조정한다.
- 소개 문장의 max-width와 line-height를 읽기 좋게 조정한다.
- 주요 링크는 너무 화려하지 않게 CTA처럼 보이게 한다.
- 레퍼런스 토큰을 쓰더라도 색상 전체 교체보다 제목 위계와 여백 리듬을 우선한다.
- 섹션 여백은 데스크톱과 모바일에서 따로 확인한다.

제약:
- 새 라이브러리 추가하지 마.
- 외부 폰트 추가하지 마.
- About / Projects / Posts 데이터 구조는 건드리지 마.
- 관련 없는 파일은 수정하지 마.
- 아직 수정하지 말고, 먼저 원인 후보와 최소 수정 계획을 제안해줘.

완료 후:
1. 변경한 파일 목록
2. 왜 바꿨는지
3. desktop 확인 결과
4. 390px mobile 확인 결과
5. npm run build 필요 여부
를 알려줘.
```

## 승인 후 프롬프트

```text
좋아. 방금 제안한 Home hero 최소 수정 계획대로 진행해줘.

진행할 때:
- 한 번에 너무 많은 스타일을 바꾸지 마.
- 기존 색상 톤은 유지해.
- 수정 후 Codex Browser에서 / 화면을 desktop과 390px mobile로 확인해줘.
```
