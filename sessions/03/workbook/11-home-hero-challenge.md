# 11. Home hero 챌린지

## 목표

Home 첫 화면의 첫인상과 정보 위계를 개선합니다.

## 고를 수 있는 문제

```text
제목이 너무 크거나 작음
소개 문장이 약함
CTA 링크가 눈에 안 띔
첫 화면 여백이 과함
390px 모바일에서 제목이 4줄 이상 깨짐
```

## 요청 예시

```text
@브라우저 또는 @Browser로 / 화면을 봐줘.
Target은 Home hero 제목과 소개 문장이야.

Problem:
- 제목과 소개 문장 사이 간격이 넓어서 첫 화면이 비어 보임
- 390px 모바일에서 제목이 너무 많이 줄바꿈됨

Direction:
- 제목 크기를 clamp() 기준으로 조정
- 소개 문장 max-width와 margin을 줄임
- 전체 색상 톤은 유지

아직 수정하지 말고 최소 수정 계획만 말해줘.
```

## 완료 기준

- [ ] desktop에서 첫 화면 위계가 분명하다.
- [ ] 390px에서 제목이 과하게 깨지지 않는다.
- [ ] 변경 파일과 이유를 설명할 수 있다.
