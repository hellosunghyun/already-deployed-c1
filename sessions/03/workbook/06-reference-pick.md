# 06. 레퍼런스 사이트 고르기

## 목표

디자인을 막연히 말하지 않고 참고할 레퍼런스를 고릅니다.

## 참고할 수 있는 곳

```text
https://getdesign.md/
https://styles.refero.design/
https://designmd.app/
직접 찾은 홈페이지 URL
```

## 고르는 기준

많이 고르지 않습니다.
오늘은 **1개만** 고릅니다.

```text
내 사이트와 분위기가 가까운가?
텍스트 중심 홈페이지에 적용 가능한가?
모바일에서도 무리 없을 것 같은가?
원하는 요소 하나만 뽑을 수 있는가?
```

## 레퍼런스 기록 폼

```text
Reference URL:
마음에 드는 이유:
가져오고 싶은 요소 하나:
가져오지 않을 것:
내 홈페이지 적용 위치:
```

## Ready Gate

- [ ] 레퍼런스 URL 1개를 골랐다.
- [ ] 전체 복제가 아니라 가져올 요소 1개를 정했다.
- [ ] 버릴 요소도 적었다.
