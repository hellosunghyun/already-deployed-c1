# Slide 28. 이제 워크북으로 갑니다

워크북에서는 각자 화면을 기준으로 진행합니다.

질문할 때는 아래를 함께 남깁니다.

```text
수업 레포 링크
내 개인 레포 링크
기존 2회차 레포에서 이어서 진행 중인지
URL
Viewport
선택한 영역
문제 설명
원하는 방향
수정 후 확인 결과
```

끝까지 못 해도 좋습니다.

**정확한 디자인 요청 1개**가 남으면 다음 세션으로 이어갈 수 있습니다.
