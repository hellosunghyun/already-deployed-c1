# Slide 15. AGENTS.md·DESIGN.md·D-001의 역할

세 문서는 같은 내용을 반복하지 않습니다.

| 파일 | 답하는 질문 | 남길 내용 |
|---|---|---|
| `AGENTS.md` | 어떻게 작업할까? | 범위, 금지사항, 검증·백로그 규칙 |
| `DESIGN.md` | 어떤 시각 규칙을 지킬까? | 선택한 토큰과 적용·비적용 원칙 |
| `docs/design-backlog/D-001.md` | 이번에 무엇을 고칠까? | 6좌표, Allowed files, 할 일, 검증, 상태 |

```text
반복 규칙 → AGENTS.md
디자인 기준 → DESIGN.md
이번 한 항목 → D-001.md
```
