# Slide 11. 레퍼런스는 토큰으로 번역합니다

레퍼런스 전체를 복제하지 않습니다.

```text
Color       색의 역할
Typography  크기·굵기·줄 간격
Spacing     내부·외부 간격
Radius      모서리 둥글기
Border      테두리 굵기·색
Shadow      그림자·레이어
Component   Hero·Navigation·Card·List 규칙
```

```text
가져올 것: 카드 제목과 본문의 위계
가져오지 않을 것: 로고·사진·문구·애니메이션
```

레퍼런스는 복사 대상이 아니라 **요구사항 재료**입니다.
