# Slide 23. D-001은 done 또는 blocked로 닫습니다

## `done`

```text
Actual changed files: [실제 변경 파일]
Verification: desktop / 390x844 / keyboard / build 모두 pass
Deployment: commit SHA / Actions green / Pages URL 확인
Evidence: before / after 경로
Status: done
```

## `blocked`

```text
Failed check: [실패한 검증]
Observed result: [오류 또는 화면 증거]
Deployment: no-deploy / 미실행 항목은 not run
Next action: [다음에 할 한 가지]
Status: blocked
```

실패를 숨기지 않는 기록도 완성된 결과입니다.
