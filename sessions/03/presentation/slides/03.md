# Slide 03. 오늘 다루는 범위

오늘은 아래를 다룹니다.

- 기존 2회차 레포와 Codex 채팅에서 이어서 작업하기
- Plan mode로 먼저 수정 계획 받기
- `@브라우저` / `@Browser`로 화면 확인하기
- 태그가 안 될 때 브라우저 설정 켜기
- 스크린샷과 브라우저 주석으로 Target 고정하기
- 레퍼런스를 디자인 토큰으로 분해하기
- 원하는 요소 하나만 가져오기
- AGENTS.md에 디자인 백로그 남기기
- 모바일과 build로 검증하기

범위는 넓지만, 성공 기준은 **정확한 수정 요청 1개**부터 시작합니다.
