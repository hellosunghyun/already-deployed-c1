# Slide 03. 오늘 다루는 범위

오늘은 아래를 다룹니다.

- 스크린샷 기반 피드백
- Codex Browser와 browser comments
- 화면 요소/영역 선택 요청
- 레퍼런스 분해
- Home hero 시각 위계
- Navigation과 레이아웃 밀도
- Projects 카드와 Posts 목록 개선
- 모바일 폭 확인
- 색 대비와 focus 상태
- build / commit / deploy 확인

범위는 넓지만, 성공 기준은 **정확한 수정 요청 1개**부터 시작합니다.

<details><summary>슬라이드 모습과 강조점</summary>

**슬라이드 모습**

- 핵심 문장을 크게 보여줍니다.
- 코드블록은 참가자가 그대로 따라 쓸 수 있는 형태로 둡니다.
- 시각적 예시는 말로 길게 설명하지 않고, 실습에서 브라우저 화면을 보며 연결합니다.

**강조해야 하는 내용**

- 디자인 수정은 감상평이 아니라 구체적 요구사항입니다.
- Codex에게 바로 실행시키기보다 먼저 원인 후보와 최소 수정 계획을 받습니다.
- 모바일과 build 검증까지가 하나의 수정 단위입니다.

</details>

<details><summary>발표자 노트</summary>

범위가 넓음을 숨기지 않습니다. 대신 모든 항목을 같은 완성도로 끝내는 수업이 아니라 정확한 요청을 만드는 수업임을 분명히 합니다.

</details>
