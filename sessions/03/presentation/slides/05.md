# Slide 05. 시작 Gate와 복구 경로

먼저 Codex에게 현재 상태만 확인시킵니다.

```text
새 프로젝트를 만들지 말고 현재 레포를 읽어줘.
수정하지 말고 아래만 알려줘.

- 현재 branch와 변경 파일
- Home·About·Projects·Posts 존재 여부
- 설치와 실행에 필요한 명령
- AGENTS.md 존재 여부
```

진행 경로:

```text
A  2회차 완료 레포 → 그대로 진행
B  일부 페이지만 있음 → 존재하는 한 페이지에서 진행
C  실행 불가·레포 없음 → 수업 예제 레포로 진행
```
