# Slide 07. Browser 설치·권한·fallback

Codex 데스크톱 앱에서:

```text
Plugins Directory → Browser 설치
→ @Browser 자동완성 확인
→ 권한 기본값: 나 대신 승인
→ 주석 스크린샷 포함
```

수업 기본 요청:

```text
@Browser [터미널에서 복사한 실제 Local URL]을 열어줘.
```

Browser가 보이지 않거나 지원되지 않으면:

```text
일반 브라우저로 같은 URL 열기
→ 스크린샷 첨부
→ 6좌표를 텍스트로 전달
```
