# Slide 06. 개발 서버와 실제 Local URL

추측한 주소가 아니라 터미널이 출력한 주소를 사용합니다.

```text
1. package.json의 명령 확인
2. 의존성이 없으면 npm ci
3. npm run dev
4. 터미널의 Local URL 전체를 복사
5. 일반 브라우저에서 Home 화면 확인
```

```text
예: http://localhost:4321/
예: http://localhost:4321/already-deployed-c1/
```

포트와 base path는 레포마다 다를 수 있습니다.
