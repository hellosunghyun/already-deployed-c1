# Slide 06. 좋은 디자인 요청의 6좌표

디자인 요청에는 6가지 좌표가 필요합니다.

```text
URL       어느 페이지인가
Viewport  어떤 화면 크기인가
Target    어느 요소/영역인가
Problem   무엇이 문제인가
Direction 어떤 방향으로 바꿀 것인가
Constraint 유지할 것과 하지 말아야 할 것
```

이 6개가 있으면 AI가 덜 추측합니다.

**슬라이드 모습**

- 핵심 문장을 크게 보여줍니다.
- 코드블록은 참가자가 그대로 따라 쓸 수 있는 형태로 둡니다.
- 시각적 예시는 말로 길게 설명하지 않고, 실습에서 브라우저 화면을 보며 연결합니다.

**강조해야 하는 내용**

- 디자인 수정은 감상평이 아니라 구체적 요구사항입니다.
- Codex에게 바로 실행시키기보다 먼저 원인 후보와 최소 수정 계획을 받습니다.
- 모바일과 build 검증까지가 하나의 수정 단위입니다.
