# Slide 08. Codex Browser는 같이 보는 화면입니다

Codex의 in-app browser는 Codex와 사용자가 **같은 렌더링 화면을 보는 공간**입니다.

오늘 사용하는 흐름:

```text
로컬 서버 실행
→ Codex Browser에서 URL 열기
→ 특정 영역에 comment 달기
→ comment를 기준으로 수정 요청
→ 다시 Browser로 확인
```

화면을 말로 설명하기보다, **영역을 찍고 말합니다.**

<details><summary>슬라이드 모습과 강조점</summary>

**슬라이드 모습**

- 핵심 문장을 크게 보여줍니다.
- 코드블록은 참가자가 그대로 따라 쓸 수 있는 형태로 둡니다.
- 시각적 예시는 말로 길게 설명하지 않고, 실습에서 브라우저 화면을 보며 연결합니다.

**강조해야 하는 내용**

- 디자인 수정은 감상평이 아니라 구체적 요구사항입니다.
- Codex에게 바로 실행시키기보다 먼저 원인 후보와 최소 수정 계획을 받습니다.
- 모바일과 build 검증까지가 하나의 수정 단위입니다.

</details>

<details><summary>발표자 노트</summary>

OpenAI 문서의 in-app browser와 visual comments를 수업 방식에 연결합니다. 참가자가 화면 위에 주석을 다는 것이 단순 편의 기능이 아니라 요구사항 정확도를 높이는 도구임을 이해하게 합니다.

</details>
