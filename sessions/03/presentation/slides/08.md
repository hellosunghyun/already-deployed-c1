# Slide 08. Baseline과 Browser 주석

수정 전에 **현재 화면을 먼저 저장**합니다.

```text
1. @Browser로 실제 Local URL 열기
2. 현재 desktop 화면 캡처
3. Annotation mode 켜기
4. 고칠 영역을 클릭하거나 드래그
5. 문제 문장을 쓰고 저장
6. 주석을 Codex 채팅으로 전송
```

주석 예시:

```text
이 카드의 제목·설명·태그가 비슷하게 보여
읽는 순서가 약합니다.
```

Browser가 없으면 같은 viewport의 스크린샷에 표시하고 텍스트로 설명합니다.
