# Slide 08. 새로 시작하지 않습니다

3회차의 기준은 이미 있는 2회차 레포입니다.

```text
기존 레포
→ 기존 Codex 프로젝트
→ 가능하면 기존 채팅
→ 현재 화면 확인
→ 디자인 수정
```

AI에게 먼저 말합니다.

```text
새 프로젝트를 만들지 말고,
현재 2회차 Astro 홈페이지에서 이어서 작업해줘.
```
