# Slide 22. commit부터 Pages까지 확인합니다

build가 통과하면 변경을 설명받고 승인합니다.

```text
변경 파일과 검증 결과를 요약해줘.
관련 없는 변경이 없으면 이 변경만 commit하고 push해줘.
```

그다음 실제 배포 표면을 확인합니다.

```text
1. commit SHA와 push 대상 branch
2. GitHub Actions workflow 결과
3. GitHub Pages 실제 URL
4. 수정한 페이지와 링크·asset 렌더링
```

`push 성공`과 `사이트 배포 성공`은 다른 증거입니다.
