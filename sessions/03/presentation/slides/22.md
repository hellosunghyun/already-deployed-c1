# Slide 22. 레퍼런스는 복사가 아니라 토큰으로 번역합니다

레퍼런스를 볼 때 전체를 따라 하지 않습니다.

참고할 수 있는 곳:

```text
getdesign.md          브랜드/제품별 DESIGN.md 분석
styles.refero.design  실제 제품 화면 기반 AI-readable style
designmd.app          ready-to-use DESIGN.md와 format 설명
직접 찾은 홈페이지     원본 화면을 보고 토큰 추출
```

분해해서 가져옵니다.

```text
Color / Typography / Spacing / Shape / Elevation / Layout / Component
```

레퍼런스는 취향이 아니라 **요구사항 재료**입니다.

**강조해야 하는 내용**

- getdesign.md, Refero Styles, designmd.app은 레퍼런스 방향을 빠르게 잡는 도구입니다.
- 디자인 토큰은 색, 글자, 여백, 모양 같은 반복 규칙입니다.
- Codex에게는 토큰과 적용 영역을 같이 줘야 합니다.
