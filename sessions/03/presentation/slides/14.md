# Slide 14. 증거 뒤에 최신 Plan을 받습니다

지금까지 모은 입력을 모두 넣고 최종 Plan을 갱신합니다.

```text
/plan

현재 baseline, Browser 주석, 6좌표, 토큰 브리프,
선택한 A/B/C 경로를 기준으로 최신 Plan을 작성해줘.

포함할 것:
- 원인과 Target
- 수정 파일과 Allowed files
- 바꾸지 않을 것
- desktop·390x844·키보드·build 검증
- 실패 시 blocked 기준

아직 구현하지 마.
```

증거가 생기기 전에 만든 Plan은 실행하지 않습니다.
