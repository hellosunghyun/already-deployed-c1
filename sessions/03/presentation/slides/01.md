# Slide 01. 화면 증거를 배포 기록까지 연결하기

## 배포했는데요? 1기 — 3회차

오늘은 막연히 “예쁘게”가 아니라, **보이는 문제 하나를 증거와 기준으로 고치는 법**을 배웁니다.

```text
화면 증거 → 작은 작업 계약 → 한 항목 수정
→ desktop·390x844·키보드·build
→ 배포 확인과 결과 기록
```

AI가 파일을 바꾼 순간이 아니라, **화면과 배포 결과를 확인한 순간**이 끝입니다.
