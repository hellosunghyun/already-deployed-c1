# Slide 09. 좋은 디자인 요청의 6좌표

6좌표는 AI가 추측하지 않게 하는 작업 주소입니다.

```text
1. Where       URL + Viewport
2. Target      고칠 요소 하나
3. Evidence    screenshot 또는 Browser 주석
4. Problem     화면에서 관찰한 문제
5. Direction   원하는 변화
6. Constraint  유지할 것·하지 않을 것
```

```text
Where: /projects, 390x844
Target: 첫 번째 프로젝트 카드
Evidence: 첨부한 before 화면의 주석 1
Problem: 제목·설명·태그의 위계가 약함
Direction: 제목은 강하게, 태그는 덜 튀게
Constraint: 데이터·색상 톤·의존성 유지
```

<details><summary>발표자 노트</summary>

URL만 쓰고 viewport를 생략하거나, 스크린샷만 첨부하고 Target을 생략하지 않게 합니다. `Where`에 URL과 viewport를 함께 적고, 증거는 별도 좌표로 명시합니다. Direction과 Constraint가 수정 범위를 닫습니다.

</details>
