# Slide 09. Plan mode는 수정 전 계약서입니다

복잡한 디자인 수정은 바로 실행하지 않습니다.

```text
/plan
```

또는 지원되는 경우:

```text
Shift + Tab
```

Plan에 있어야 할 것:

```text
Target
수정 파일 후보
하지 않을 일
검증 방법
모바일 확인
```

계획을 확인한 뒤 **하나만 실행**합니다.
