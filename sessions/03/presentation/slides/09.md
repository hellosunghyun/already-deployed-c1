# Slide 09. Browser comments는 위치를 고정합니다

브라우저 주석은 이런 말을 대신합니다.

```text
여기 말고 저기,
위쪽 카드 말고 첫 번째 카드,
전체 페이지 말고 이 제목 영역.
```

Browser comment에 붙일 말:

```text
이 영역의 제목과 설명 위계를 더 분명하게 해줘.
색은 유지하고 font-size, font-weight, gap만 조정해줘.
```

주석은 위치, 프롬프트는 기준입니다.

<details><summary>슬라이드 모습과 강조점</summary>

**슬라이드 모습**

- 핵심 문장을 크게 보여줍니다.
- 코드블록은 참가자가 그대로 따라 쓸 수 있는 형태로 둡니다.
- 시각적 예시는 말로 길게 설명하지 않고, 실습에서 브라우저 화면을 보며 연결합니다.

**강조해야 하는 내용**

- 디자인 수정은 감상평이 아니라 구체적 요구사항입니다.
- Codex에게 바로 실행시키기보다 먼저 원인 후보와 최소 수정 계획을 받습니다.
- 모바일과 build 검증까지가 하나의 수정 단위입니다.

</details>

<details><summary>발표자 노트</summary>

브라우저 주석은 문제 위치를 고정하고, 프롬프트는 어떤 방향으로 바꿀지를 정합니다. 둘 중 하나만 있으면 부족합니다.
