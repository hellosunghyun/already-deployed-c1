# Slide 25. 선택 B — Navigation·레이아웃

## 셋 중 하나만 선택

Navigation 또는 레이아웃에서 Target 하나를 고릅니다.

- 현재 페이지 표시
- 링크 간격과 터치 영역
- 모바일 줄바꿈과 Header 높이
- 컨테이너 폭과 섹션 정렬

```text
기준: desktop과 모바일 모두에서
사용자가 현재 위치와 다음 이동을 알 수 있어야 합니다.
```
