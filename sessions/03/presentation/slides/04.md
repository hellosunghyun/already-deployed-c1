# Slide 04. 성공 기준은 누적형입니다

## 최소

- A / B / C 출발 경로를 정했습니다.
- 수정 전 화면과 문제 하나를 6좌표로 남겼습니다.
- Home / Navigation / Projects·Posts 중 영역 하나를 정했습니다.

## 표준 = 최소 +

- 레퍼런스 요소 하나를 7개 토큰으로 정리했습니다.
- 승인한 디자인 규칙을 프로젝트 루트 `DESIGN.md`에 저장했습니다.
- 증거 기반 최종 Plan과 `D-001`이 있습니다.
- `D-001` 한 항목을 실행했습니다.
- 현재 desktop과 `390x844`를 확인했습니다.

## 완료 = 표준 +

- 키보드와 `npm run build`를 확인했습니다.
- commit·push 후 Actions와 Pages 실제 URL을 확인했거나, 배포하지 못한 이유와 `no-deploy`·`not run`을 기록했습니다.
- before·after·검증 결과를 기록하고 `D-001`을 `done` 또는 `blocked`로 갱신했습니다.
