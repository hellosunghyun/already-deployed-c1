# Slide 26. 챌린지 3 — 모바일 Navigation

모바일 Navigation에서 고를 수 있는 문제:

- 링크가 너무 가까움
- 줄바꿈이 어색함
- Header 높이가 과도함
- 현재 페이지를 알기 어려움
- 터치하기 어려움

수정 기준:

```text
모바일에서는 예쁜 것보다 길을 잃지 않는 것이 먼저입니다.
```

<details><summary>슬라이드 모습과 강조점</summary>

**슬라이드 모습**

- 핵심 문장을 크게 보여줍니다.
- 코드블록은 참가자가 그대로 따라 쓸 수 있는 형태로 둡니다.
- 시각적 예시는 말로 길게 설명하지 않고, 실습에서 브라우저 화면을 보며 연결합니다.

**강조해야 하는 내용**

- 디자인 수정은 감상평이 아니라 구체적 요구사항입니다.
- Codex에게 바로 실행시키기보다 먼저 원인 후보와 최소 수정 계획을 받습니다.
- 모바일과 build 검증까지가 하나의 수정 단위입니다.

</details>

<details><summary>발표자 노트</summary>

Navigation은 실제 사용성에 직접 연결됩니다. 모바일에서 링크가 안 보이면 사이트 구조가 있어도 소용없습니다.

</details>
