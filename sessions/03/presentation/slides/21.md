# Slide 21. 원인 확인→수정→필수 검증

순서를 바꾸지 않습니다.

```text
화면 증거와 실제 파일로 원인 후보 확인
→ 선택한 파일만 수정
→ 현재 desktop 재확인
→ 390x844 재확인
→ Tab·Shift+Tab·Enter로 키보드 확인
→ npm run build
```

필수 viewport:

- 현재 사용 중인 desktop
- `390x844`

권장 추가 viewport:

- `768x1024`
- `1440x900`

문제가 발견되면 최소 수정 후 같은 순서로 다시 확인합니다.
