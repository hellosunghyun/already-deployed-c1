# Slide 27. 실패 분기와 증거 묶음

문제를 발견하면 다음 단계로 건너뛰지 않습니다.

```text
화면 문제 발견
→ 원인 확인
→ 최소 수정
→ 같은 viewport·키보드 재검증
→ build 재검증
```

해결되면 배포하고 `done`, 해결되지 않으면 배포 완료로 처리하지 않고 `blocked`로 기록합니다.

최종 증거 묶음:

```text
before / after
D-001 상태와 실제 변경 파일
desktop / 390x844 / keyboard / build 결과
commit SHA / Actions 결과 / Pages URL
```
