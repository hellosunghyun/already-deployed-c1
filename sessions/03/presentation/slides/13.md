# Slide 13. 셋 중 하나만 선택합니다

```text
A  Home hero
   제목·소개·첫 화면 여백·이동 경로

B  Navigation·레이아웃
   현재 위치·링크 간격·컨테이너 폭·모바일 줄바꿈

C  Projects·Posts
   카드 또는 목록의 정보 위계·간격·링크
```

선택 규칙:

- 오늘은 A/B/C를 모두 하지 않습니다.
- 선택한 경로에서 Target 하나만 정합니다.
- 선택 결과를 6좌표와 토큰 브리프에 합칩니다.
