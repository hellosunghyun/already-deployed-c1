# 3회차 발표자료 인덱스

이 발표자료는 Markdown 뷰어에서 슬라이드처럼 한 장씩 넘겨가며 설명하기 위한 자료입니다.
각 슬라이드는 별도 파일로 나누었습니다.

## 발표 시간 목표

권장 발표 시간은 30분 내외입니다.
목표는 디자인 이론 강의가 아니라, 참가자가 Codex에게 **화면 기반 요구사항**을 정확히 전달할 수 있게 만드는 것입니다.

## 발표자료의 역할

3회차 발표자료는 아래 개념을 같은 언어로 맞추기 위한 자료입니다.

- 스크린샷은 증거, 텍스트는 요구사항
- Codex Browser와 browser comments
- 좋은 디자인 요청의 6좌표
- getdesign.md, Refero Styles, designmd.app 같은 레퍼런스에서 원하는 요소만 고르기
- Reference를 디자인 토큰으로 분해해서 요구사항으로 바꾸기
- 모바일 확인과 접근성 기본 기준
- 작은 수정과 검증 루프

## 30분 진행 리듬

| 시간 | 슬라이드 | 진행 방식 |
|---|---|---|
| 0:00-0:05 | 01-04 | 3회차 위치, 오늘 범위, 성공 기준 |
| 0:05-0:11 | 05-07 | 나쁜 요청과 스크린샷 피드백 구조 |
| 0:11-0:17 | 08-11 | Codex Browser, comments, 제약, 작은 수정 |
| 0:17-0:23 | 12-19 | 시각 위계, 여백, 타이포, 색, 카드, 모바일, Inspect |
| 0:23-0:27 | 20-23 | 좋은 프롬프트, 레퍼런스 사이트, 원하는 요소 선택, 디자인 토큰 브리프 |
| 0:27-0:30 | 24-28 | 실습 챌린지와 워크북 전환 |
