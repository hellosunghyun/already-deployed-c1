# 스크린샷 피드백 템플릿

```text
Screenshot:
URL:
Viewport:
Target:
Problem:
Direction:
Constraint:
Verification:
```

## 예시

```text
URL: /projects
Viewport: 390x844
Target: 첫 번째 프로젝트 카드
Problem: 제목, 설명, 태그가 모두 비슷하게 보여 읽는 순서가 약함
Direction: 제목 굵기 강화, 설명 줄간격 조정, 태그는 덜 튀게
Constraint: 새 라이브러리 추가 금지, 데이터 구조 유지
Verification: @브라우저 또는 @Browser로 390px 확인 후 npm run build
```
