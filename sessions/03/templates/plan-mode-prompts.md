# Plan mode 프롬프트 모음

## 계획만 받기

```text
/plan

기존 2회차 Astro 홈페이지 레포에서 이어서 작업해줘.
새 프로젝트를 만들지 말고, 현재 화면의 디자인 문제를 하나 고치는 계획만 세워줘.

계획에 포함할 것:
- 확인할 URL
- 수정 Target
- 수정 파일 후보
- 하지 않을 일
- 검증 방법
- 모바일 확인 방법

아직 파일을 수정하지 마.
```

## 계획 실행하기

```text
좋아. 방금 계획 중 D-001만 실행해줘.
다른 항목은 건드리지 마.
수정 전 변경 파일 후보를 말하고, 수정 후 @브라우저 또는 @Browser로 확인해줘.
마지막에는 npm run build 결과를 알려줘.
```

## 멈추기

```text
멈춰.
지금까지 수정한 파일과 이유만 요약해줘.
추가 수정은 하지 마.
```
