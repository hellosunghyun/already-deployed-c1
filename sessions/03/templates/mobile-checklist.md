# 모바일 확인 체크리스트

## 확인 viewport

```text
390x844  모바일 기준
768x1024 태블릿 기준
1024x768 작은 노트북 기준
1440x900 데스크톱 기준
```

## 공통 체크

- [ ] 가로 스크롤이 없다.
- [ ] Header가 화면을 과하게 차지하지 않는다.
- [ ] Navigation 링크가 보인다.
- [ ] 링크 사이 간격이 너무 좁지 않다.
- [ ] 제목이 너무 많이 줄바꿈되지 않는다.
- [ ] 본문 줄 길이가 읽기 어렵지 않다.
- [ ] 카드가 1열로 자연스럽게 내려온다.
- [ ] CTA 또는 자세히 보기 링크가 터치하기 쉽다.
- [ ] Footer가 콘텐츠와 겹치지 않는다.

## 페이지별 체크

### Home

- [ ] 첫 화면에서 누구의 사이트인지 알 수 있다.
- [ ] 한 줄 소개가 제목보다 약하지만 읽힌다.
- [ ] About / Projects / Posts로 이동할 수 있다.

### About

- [ ] 문단이 너무 길지 않다.
- [ ] 소제목과 본문 위계가 보인다.

### Projects

- [ ] 카드 제목이 먼저 보인다.
- [ ] 설명, 역할, 도구, 결과가 구분된다.
- [ ] 자세히 보기 링크가 보인다.

### Posts

- [ ] 글 제목이 먼저 보인다.
- [ ] 날짜와 태그가 보조 정보처럼 보인다.
- [ ] 요약이 너무 좁거나 길지 않다.

## Codex에게 보낼 문장

```text
아래 모바일 체크리스트를 기준으로 현재 사이트를 확인해줘.

확인 viewport:
- 390x844
- 768x1024
- 1440x900

확인 URL:
- /
- /about
- /projects
- /posts

체크리스트에서 실패한 항목을 먼저 목록으로 만들고,
바로 수정하지 말고 가장 작은 수정 계획을 제안해줘.
```
