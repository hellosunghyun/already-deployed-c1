# 원하는 요소만 선택하기 템플릿

한 레퍼런스에서 한 요소만 선택해 D-001 입력값으로 확정합니다.

```text
Where (URL + Viewport): [적용할 내 페이지와 화면 크기]
Target: [입력]
Evidence: [현재 화면과 레퍼런스 스크린샷 경로 또는 첨부명]
Problem: [입력]
Direction: [입력]
Constraint: [입력]

Reference source: [사이트 이름]
Reference URL: [입력]
Selected element: [하나만 입력]
선택 이유: [내 Problem과 연결해 입력]

Bring: [가져올 특성]
Avoid: [가져오지 않을 특성]

Color: [입력]
Typography: [입력]
Spacing: [입력]
Radius: [입력]
Border: [입력]
Shadow: [입력]
Component: [입력]

Allowed files: [파일 경로 목록]
Verification: [현재 desktop, 390x844, npm run build]
```

다른 요소를 함께 적용하고 싶다면 이번 D-001에 합치지 않고 D-002 후보로 남깁니다.
