# Before / After 기록지

```text
기록 날짜: [YYYY-MM-DD]
D-001 제목: [입력]
Status: [done / blocked]

Where (URL + Viewport): [입력]
Target: [입력]
Evidence: [Before 스크린샷 경로, 첨부명 또는 Browser 주석]
Problem: [수정 전 관찰]
Direction: [원한 결과]
Constraint: [지킨 제약]

Before 스크린샷 경로 또는 첨부명: [입력]
After 스크린샷 경로 또는 첨부명: [입력]

Reference URL: [입력]
Selected element: [입력]
Bring: [입력]
Avoid: [입력]

실제 변경 파일:
- [파일 경로]

After 결과: [관찰 가능한 변화]
Summary: [한 문장 결과 요약]
현재 desktop [실제 viewport] 확인: [pass / fail / not run]
390x844 확인: [pass / fail / not run]
npm run build: [pass / fail / not run]
실패 로그: [없음 / 핵심 오류]

commit SHA와 메시지: [없음 / 입력]
push: [pass / fail / not run]
GitHub Actions: [pass / fail / not run]
GitHub Pages URL과 확인 결과: [입력]

남은 문제: [없음 / 입력]
다음 작업: [없음 / D-002 후보]
```

확인하지 않은 항목은 성공으로 추정하지 않고 `not run`으로 남깁니다.
