# Codex 브라우저 / Browser 프롬프트

## 열기

```text
@브라우저 http://localhost:4321/ 을 열어줘.
```

영어 UI:

```text
@Browser http://localhost:4321/ 을 열어줘.
```

## 주석 기준 수정 계획

```text
내가 브라우저 주석으로 표시한 영역을 기준으로 봐줘.
아직 수정하지 말고 문제 원인 후보와 최소 수정 계획만 말해줘.
```

## 수정 후 확인

```text
@브라우저 또는 @Browser로 수정한 URL을 다시 확인해줘.
390x844 모바일에서도 제목, Navigation, 카드 간격이 깨지지 않는지 봐줘.
```

## 태그가 안 될 때

```text
설정 → 통합 → 브라우저에서 브라우저 플러그인을 켰는지 확인해줘.
주석 스크린샷은 항상 포함으로 설정해줘.
```
